## What is available today

The application includes inventory records, replenishment, purchasing controls, payment history, activity and clinic settings. A bounded automatic-purchasing run completed a public testnet supplier payment without approval for that individual order. Payment and delivery were verified as separate events.

The current release uses synthetic clinic records, example supplier offers and **CCUSD on NEAR testnet**, a demonstration token with no cash value. CCUSD is not Circle USDC. Mainnet payments and real supplier ordering are not activated. Read [mainnet readiness](/docs/mainnet-readiness) for the evidence and remaining release gates.
